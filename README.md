# YouTube → Obsidian Zettelkasten (MD Button)

**Версия:** 1.2.0 · **Тип:** Userscript (JavaScript / Tampermonkey) · **Язык заметок:** русский

Скрипт добавляет кнопку **MD** под видео YouTube и создаёт единую Markdown-заметку для базы знаний Obsidian по методике Zettelkasten. Он извлекает доступные метаданные и субтитры, группирует текст по главам автора или временным блокам, а при наличии работающего ИИ дополняет материал конспектом, анализом и связанными понятиями.

> **Важно:** полнота заметки зависит от доступности субтитров и качества ответа выбранной модели. Скрипт не гарантирует извлечение 100% сведений, показанных только на экране, и не выполняет распознавание речи или OCR самостоятельно.

## Возможности

- Кнопка **MD** на странице просмотра YouTube.
- Получение названия видео, канала, ссылки, длительности, даты публикации, описания, ключевых слов и доступных субтитров.
- Предпочтение русскоязычных субтитров; запрос перевода на русский, если дорожка допускает перевод.
- Разделение транскрипции по главам из описания либо по блокам примерно по 3 минуты.
- Навигация по видео с кликабельными таймкодами.
- Генерация аналитической заметки с помощью встроенной панели YouTube **«Задать вопрос»**, локального **llama.cpp**, **OpenRouter** или **Google Gemini API**.
- Формирование одного `.md`-файла с YAML frontmatter, Obsidian-ссылками `[[...]]`, Mermaid и индексом понятий.
- Скачивание Markdown-файла, открытие через `obsidian://new` или оба действия одновременно.
- Режим без ИИ: транскрипция, метаданные и заготовка для дальнейшего заполнения.

## Требования

1. Браузер с поддержкой менеджера пользовательских скриптов.
2. Установленный **Tampermonkey** с разрешёнными необходимыми возможностями (`GM_xmlhttpRequest`, `GM_download`, `GM_getValue`, `GM_setValue`).
3. Доступ к YouTube.
4. **Obsidian** — для открытия и ведения базы знаний (необязателен, если нужен только Markdown-файл).
5. Для внешнего ИИ — доступный сервер llama.cpp или API-ключ соответствующего провайдера. Встроенная функция YouTube «Задать вопрос» доступна не всем пользователям и не для каждого видео.

Скрипт ориентирован на обычные страницы просмотра `youtube.com/watch`; наличие `@match` для мобильного домена само по себе не гарантирует работу кнопки в мобильном интерфейсе.

## Установка

1. Установите Tampermonkey в браузер.
2. Создайте новый пользовательский скрипт в панели Tampermonkey.
3. Скопируйте туда исходный JavaScript из репозитория (файл с заголовком `// ==UserScript==`).
4. Сохраните скрипт и убедитесь, что он включён.
5. Откройте страницу видео на YouTube и найдите кнопку **MD** под роликом.


## Использование

**Обычный щелчок по MD** запускает создание заметки. Скрипт собирает метаданные и субтитры, при необходимости обращается к ИИ, формирует Markdown и сохраняет результат согласно настройкам.

**Правый щелчок по MD**, **Shift + щелчок** или **Ctrl + щелчок** открывает настройки. Они также доступны через меню Tampermonkey: **«⚙️ Настройки YouTube → Obsidian [MD]»**.

Во время работы текст кнопки показывает текущий этап. При ошибке откройте консоль разработчика браузера (`F12`) и найдите сообщения `[YT-Zettel]`.

## Режимы ИИ

| Режим | Поведение |
| --- | --- |
| `auto` | Сначала панель YouTube «Задать вопрос», затем при отсутствии результата — llama.cpp → OpenRouter → Gemini. |
| `youtube-ask` | Только встроенная панель YouTube. |
| `llamacpp` | Только локальный OpenAI-совместимый сервер llama.cpp. |
| `openrouter` | Только OpenRouter API. |
| `gemini` | Только Google Gemini API. |
| `none` | Без ИИ: создаётся шаблон с доступной транскрипцией и метаданными. |

Для панели YouTube в исходном коде предусмотрены две стратегии: `multi` (три последовательных вопроса, по умолчанию) и `full` (один вопрос). **В текущем окне настроек переключателя стратегии нет**: для её изменения нужно отредактировать `askStrategy` в `DEFAULT_CONFIG` исходного скрипта либо изменить сохранённое значение через API хранилища Tampermonkey.

### Пример настройки llama.cpp

Запустите `llama-server` с загруженной моделью и доступным OpenAI-совместимым endpoint. В настройках скрипта укажите:

```text
Режим ИИ:       Сразу локальный llama.cpp сервер
URL сервера:    http://127.0.0.1:8080/v1/chat/completions
```

По умолчанию скрипт передаёт имя модели `local-model` и заголовок `Authorization: Bearer sk-llamacpp-local`. Имя модели задаётся параметром `llamacppModel` в `DEFAULT_CONFIG`; **отдельного поля для него в текущем окне настроек нет**. Проверьте, какие имя модели и авторизация поддерживаются вашим сервером.

Для OpenRouter и Gemini укажите API-ключ и модель в окне настроек. Ключи сохраняются в хранилище Tampermonkey, поэтому не публикуйте их и учитывайте риски использования браузерного хранилища.

## Сохранение заметок

| Режим | Результат |
| --- | --- |
| `download` | Загрузка `.md` в каталог загрузок браузера; по умолчанию запрашивается подпапка `Obsidian_YouTube_Zettelkasten`. |
| `obsidian-uri` | Открытие ссылки `obsidian://new` для создания заметки в Obsidian. |
| `both` | Оба способа одновременно. |

По умолчанию для Obsidian используется папка `90_sources/YouTube`, а имя Vault не задано. **Поле для редактирования папки Obsidian в текущем окне настроек отсутствует**: её можно изменить через `obsidianFolder` в `DEFAULT_CONFIG`. Поведение подпапки загрузок зависит от настроек браузера и Tampermonkey. Очень длинные заметки могут превышать практические ограничения URL-схемы `obsidian://new`; в таком случае надёжнее использовать скачивание `.md`.

## Структура Markdown-заметки

Готовый файл содержит YAML frontmatter: `id`, `title`, `aliases`, `description`, `author`, `channel`, `source`, `video_id`, `published`, `duration`, `created`, `updated`, `lang`, `type`, `status`, `tags`, `topics`, `keywords` и связи `zettel`.

При полноценном ответе ИИ промпт запрашивает пять частей:

1. **Literature Note** — хронологический конспект, инструкции, команды, параметры, глоссарий, ресурсы и транскрипция.
2. **Contextual & Analytical Note** — внешний контекст, альтернативы, ограничения и практические выводы.
3. **Permanent Notes** — самостоятельные атомарные заметки с внутренними ссылками.
4. **Knowledge Graph** — диаграмма Mermaid.
5. **Индекс знаний** — перечни концептов, инструментов, алгоритмов, библиотек и связанных сущностей.

В режиме без ИИ создаётся **шаблон** всех пяти частей: аналитические разделы и атомарные заметки нужно заполнить вручную. Скрипт сохраняет всё **в одном файле**, а не создаёт отдельные файлы для каждой Permanent Note. Раздел индекса содержит поля вида `Concepts::`, `Tools::` и т. п.; их интерпретация плагином Dataview зависит от размещения и синтаксиса — в резервном шаблоне они помещены в блок `text` и служат прежде всего заготовкой.

## Настройки по умолчанию

```javascript
aiMode: 'auto'
askStrategy: 'multi'
blockIntervalSec: 180
llamacppUrl: 'http://127.0.0.1:8080/v1/chat/completions'
llamacppModel: 'local-model'
openrouterModel: 'google/gemini-2.5-flash'
geminiModel: 'gemini-2.5-flash'
saveMode: 'download'
downloadSubfolder: 'Obsidian_YouTube_Zettelkasten'
obsidianVault: ''
obsidianFolder: '90_sources/YouTube'
```

Настройки сохраняются через `GM_setValue` и восстанавливаются через `GM_getValue`. Уже сохранённые значения имеют приоритет над изменениями `DEFAULT_CONFIG`.

## Известные ограничения

- YouTube периодически меняет DOM, интерфейс и способы доступа к субтитрам: кнопку или панель «Задать вопрос» может потребоваться адаптировать.
- Скрипт получает **существующие субтитры**, а не распознаёт звук самостоятельно. При отсутствии субтитров выводится соответствующее сообщение.
- Главы определяются по временным меткам **в описании видео**; не все способы разметки глав YouTube охвачены.
- При использовании внешних LLM транскрипция в запросе ограничена первыми **75 000 символами**, описание — первыми **4 000 символами**. При этом в готовую заметку скрипт старается вставить полную полученную транскрипцию.
- Результаты ИИ могут содержать неточности, вымышленные команды и ссылки. Перед практическим применением проверяйте их по оригинальному видео и документации.
- Режим `auto` не объединяет ответы разных ИИ: используется первый полученный непустой результат.
- Сохранение через `obsidian://new` зависит от регистрации протокола в ОС и может потребовать подтверждения браузера.
- Селекторы интерфейса YouTube и сценарий отправки вопроса могут не работать для некоторых локализаций, аккаунтов и вариантов интерфейса.

## Диагностика

**Нет кнопки MD.** Проверьте, что Tampermonkey включён, скрипт активен и открыта страница `/watch`. Перезагрузите страницу. При изменении интерфейса YouTube может потребоваться обновить DOM-селекторы.

**Нет транскрипции.** Убедитесь, что у видео есть доступные субтитры. Проверьте сообщения в консоли браузера и доступность запросов к дорожке субтитров.

**Не работает локальный ИИ.** Проверьте URL endpoint, доступность `llama-server`, имя модели, разрешения Tampermonkey на запросы к `127.0.0.1` и консоль браузера.

**Obsidian не открывается.** Проверьте установленное приложение, имя Vault, регистрацию протокола `obsidian://` и длину передаваемого содержимого. Используйте режим `download` как резервный.

## Безопасность и конфиденциальность

При обращении к OpenRouter или Gemini скрипт передаёт выбранному провайдеру метаданные видео и текст доступной транскрипции. При использовании встроенного ИИ YouTube вопросы отправляются через интерфейс YouTube. Если требуется локальная обработка, выберите режим `llamacpp` и используйте собственный сервер. Не добавляйте API-ключи непосредственно в публичный репозиторий.
